# Pin Atlas

Explore microcontrollers and development boards with interactive pinouts.

**[Visit Pin Atlas](https://vikramaharshith.github.io/PinAtlas/)**

## Features

- Search and filter 30 boards and chips by manufacturer and interface.
- Hover over pins for details and highlight UART, SPI, I²C, and other functions.
- Compare devices side by side.
- View specifications, board revisions, and manufacturer references.
- Customize themes, accents, and card layouts.
- Liquid-glass controls and an interactive MicroSlats background.
